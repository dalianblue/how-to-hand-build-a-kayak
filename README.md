# 艺术级皮划艇建造技术

本书原作者吴树升先生授权公开，遵循 CC BY-SA 4.0 协议。

## 📖 内容简介

本书详细介绍了艺术级皮划艇的完整建造过程，包括：

- **设计因素** - 皮划艇性能参数分析
- **型线图绘制** - 图纸绘制原理与识图方法
- **建造基础** - 所需材料、工具和空间
- **形板放样** - 模板制作方法
- **木条加工** - 形板和龙骨加工
- **船体建造** - 船体和甲板制作
- **玻璃纤维铺设** - 外层处理
- **配件制作** - 仓口、座椅、靠背等
- **船体装配** - 各部件组装
- **船桨制作** - 船桨工艺
- **维护修理** - 日常维护和损伤修复
